08

Cumulative session pressure

Volume-weighted estimates from 09:15 through the latest completed 5m bar. First display 09:20 IST; no forming bar.

Observation only

Session buy pressure

Top 5 / absolute session %

Session sell pressure

Top 5 / absolute session %

Session pressure sums estimated buy / sell volume across every completed bar from 09:15, then divides net estimated volume by total volume. It is estimated, not executed flow; actual buy / sell volume is unavailable. Current resting depth is separate, never historically accumulated. Fresh valid depth, liquidity and complete trusted session coverage with absolute pressure at least the server threshold (default 20%) are required; a latest-bar spike, aligned depth and a historical baseline are not watchlist gates. Rank: absolute session %, weighted score, symbol. Fixed session-pressure-v1 weights: depth 20, session 15, volume 15, then VWAP, momentum, breakout, consecutive candles and independent sector peers 10 each. Optional unknown checks score zero, without reweighting. Alerts require all 8 checks, broker-only coverage, aligned latest 5m pressure, current price beyond the opening range and an unexpired TTL. Direction filters still use change from the session open.
